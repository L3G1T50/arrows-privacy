# arrows-privacy

Public hosting for the privacy policy of **Arrows: Sakura Samurai**
(`com.djxl3.arrows`), an offline single-player Android puzzle game.

Live at **<https://l3g1t50.github.io/arrows-privacy/>** — the URL referenced by
the Google Play store listing and by the in-app "Privacy policy" link.

This repo exists only because free GitHub Pages requires a public repository and
the game's source repo is private. It contains no game code.

## Editing

`docs/privacy-policy.md` in the game repo is the canonical source of this text.
Edit it there first, then mirror the change into `index.html` here and bump the
effective date in both.
